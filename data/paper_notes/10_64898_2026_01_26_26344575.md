Much of the disease surveillance data that exists is published only as a picture. Weekly situation reports carry maps of which districts reported cases, but not the table behind the map. Rebuilding that table by hand takes hours and introduces errors.

Map Liberator is an open-source web application, built in R and Shiny, that puts a static map beside the official administrative boundaries for the same country. Click the districts the map shows as affected and the result is a dataset joined to standard place names and identifiers, ready to model.

To test it I digitised eight years of Lassa fever notifications for Nigeria's 774 local government areas from Nigeria Centre for Disease Control reports. Each map took under five minutes. The tool is disease and country agnostic, and the code is on GitHub.
